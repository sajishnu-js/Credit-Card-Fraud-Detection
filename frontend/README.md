# Sentinel — Frontend

This is the Next.js web console for the Credit Card Fraud Detection project. See the
[project README](../README.md) for full setup, environment variables, and deployment
instructions.

## Quick start

```bash
npm install
npm run dev
```

Requires the backend API to be running (see the root README) and
`NEXT_PUBLIC_API_URL` set in `.env.local`.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build (TypeScript + ESLint + Next.js)
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
